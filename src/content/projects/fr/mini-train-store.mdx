# Mini Train Store : une boutique en ligne reliée aux annonces Leboncoin

## Le problème

Le commerce de trains miniatures de mon père vendait en partie par des annonces publiées sur Leboncoin. Une boutique en ligne indépendante devait proposer les mêmes produits, sans ressaisir chaque annonce à la main ni tenir deux stocks en parallèle.

Plutôt que de développer une boutique de zéro, j’ai déployé **Odoo** sur mes propres serveurs et écrit une **extension de navigateur** pour la partie propre au commerce : sortir les annonces de Leboncoin pour alimenter le catalogue.

## Architecture

L’extension est construite avec **WXT**, **Vue 3**, Tailwind CSS et TypeScript. À l’ouverture d’une page de profil Leboncoin, le **script de contenu** extrait les annonces sans aucun clic. Le **script d’arrière-plan** les enregistre dans le stockage local du navigateur, séparément pour chaque profil, et fusionne les nouveaux résultats avec ceux déjà enregistrés. La **fenêtre de l’extension** permet de changer de profil, de trier les annonces par date ou par prix, de les filtrer par statut (active, vendue, retirée) et d’en ouvrir une dans un nouvel onglet. Un module distinct dialogue avec l’API d’Odoo pour gérer les produits.

La boutique elle-même est une instance Odoo hébergée sur mon infrastructure personnelle.

## Choix techniques

- **Réutiliser Odoo plutôt que recréer une boutique.** Odoo gère le catalogue, les prix et la vitrine ; le code spécifique ne couvre que le fonctionnement propre au commerce.
- **Extraire dans le navigateur.** L’extension ne lit que les pages ouvertes par l’utilisateur et garde les annonces dans le navigateur, sans serveur de collecte séparé.
- **Faire correspondre deux modèles de données.** Une annonce et un produit n’ont pas les mêmes champs : prix, statut, description, catégories et images demandent une étape de correspondance avant publication.

## Résultats

La boutique est en ligne sur **[minitrainstore.fr](https://www.minitrainstore.fr/)**. Le dépôt contient l’extension et les ressources de la boutique, comme ses cartes de visite.

## Limites

L’extraction dépend du HTML de Leboncoin : un changement de son côté peut casser les sélecteurs, donc le code d’analyse doit rester court et facile à corriger. Les annonces sont stockées dans le stockage local d’un seul navigateur et ne sont pas partagées entre appareils.
