# System of linear equations calculator

> A C implementation of Gaussian elimination with partial pivoting for linear systems.

## Overview

A C implementation of Gaussian elimination with partial pivoting to solve arbitrary systems of linear equations.

## Engineering approach

The solver uses Gaussian elimination with partial pivoting to improve numerical handling. It is a focused numerical-algorithms exercise in C, not a general linear-algebra framework.

## Scope and limitations

Academic or research work, potentially collaborative. It illustrates an engineering method or experiment rather than claiming a commercially deployed product.
