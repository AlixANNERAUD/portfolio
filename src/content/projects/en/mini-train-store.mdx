# Mini Train Store: an online shop connected to Leboncoin listings

## The problem

My father's model railway business sold partly through listings on Leboncoin. An independent online shop needed the same products, without retyping every listing by hand and keeping two inventories in sync.

Rather than build a store from scratch, I deployed **Odoo** on my own servers and wrote a **browser extension** for the part that is specific to the business: getting listings out of Leboncoin and into the catalog.

## Architecture

<ArchitectureFlow title="From listing to online catalog" steps={[{ title: 'Leboncoin', detail: 'Seller profile pages opened in the browser.' }, { title: 'Content script', detail: 'Detects profile pages and extracts their listings.' }, { title: 'Background script', detail: 'Stores listings in local storage and merges them per profile.' }, { title: 'Vue 3 interface', detail: 'Review, sorting and filtering before work in Odoo.' }]} />

The extension is built with **WXT**, **Vue 3**, Tailwind CSS and TypeScript. When a Leboncoin profile page opens, the **content script** extracts the listings without any click. The **background script** saves them in the browser's local storage, separately for each profile, and merges new results with the ones already saved. The **popup** lets the user switch profiles, sort listings by date or price, filter them by status (active, sold, removed) and open any of them in a new tab. A separate module talks to the Odoo API to handle products.

The shop itself runs as an Odoo instance on my self-hosted infrastructure.

## Technical choices

- **Reuse Odoo rather than rebuild a store.** Odoo covers the catalog, prices and the storefront; custom code only covers the workflow specific to the business.
- **Extract in the browser.** The extension only reads pages the user opens and keeps the listings in the browser, with no separate scraping server.
- **Map two data models.** A listing and a store product do not have the same fields: price, status, description, categories and images need a mapping step before publication.

## Results

The shop is live at **[minitrainstore.fr](https://www.minitrainstore.fr/)**. The repository holds the extension and the shop's assets, such as its business cards.

## Limitations

The extraction depends on Leboncoin's HTML: a change on their side can break the selectors, so the parsing code has to stay small and easy to fix. The listings are stored in one browser's local storage and are not shared between devices.
