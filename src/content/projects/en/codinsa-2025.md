# Cod'INSA 2025: first place overall

## Overview

I was part of the INSA Rouen team that won Cod'INSA 2025, finishing first in the overall ranking.

## Context

Cod'INSA is a team programming contest: it tests how quickly a team can design correct algorithmic solutions and program them. As with the other competitions in this section, the placement is a collective result.
